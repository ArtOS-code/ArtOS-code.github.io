Велоскат — статическая HTML-версия сайта
=========================================

ВАРИАНТ 1. Просто открыть:
  Дважды кликните index.html — сайт откроется в браузере.

ВАРИАНТ 2. Локальный сервер (рекомендуется):
  Python:  python3 -m http.server 8080   →  http://localhost:8080
  Node:    npx serve .
  PHP:     php -S localhost:8080

ПУБЛИКАЦИЯ:
  Загрузите содержимое папки на любой хостинг (Netlify, GitHub Pages,
  обычный shared-хостинг) — сайт полностью статический, сервер не нужен.

Структура: каждая страница — отдельная папка с index.html
  /tochechnaia-svarka/           — аппараты точечной сварки TSV
  /tochechnaia-svarka/tsv-2-1/   — товар TSV-2.1
  /elektrosamokaty/              — электросамокаты
  /korzina/                      — корзина
  ... и т.д.

Корзина работает без сервера — данные хранятся в localStorage браузера.
